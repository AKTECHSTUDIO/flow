Publish to Netlify

Push content.json to GitHub → Netlify auto-deploys in ~30 seconds.

🔧 One-time GitHub setup

1. Create a free account at github.com
2. Create a repository — name it flowmatic-site
3. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained
4. Create a token with Contents: Read & Write for your repo
5. In Netlify → connect your site to the GitHub repo
6. Paste your details below (saved in your browser only)

Publish
Netlify detects the change and rebuilds your live site in about 30 seconds. No coding, no FTP.
Manual fallback — download & upload yourself
If GitHub is not set up: download content.json, then drag-and-drop your entire site folder to netlify.com/drop.

Security

Change your admin panel password. The password is SHA-256 hashed — never stored in plain text.

Change password
How admin security works
Your password is hashed with SHA-256 and stored in content.json as a hash string — the actual password is never saved anywhere.

The admin session lasts 8 hours. After that you need to log in again.

After changing your password: click 🚀 Publish (or download content.json and re-deploy) to make the new password live on Netlify.
